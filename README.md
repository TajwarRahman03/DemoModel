# SmartReply & SmartNotes — Interactive Demo

A lightweight, interactive demonstration of AI-assisted customer support workflows, built with vanilla HTML, CSS, and JavaScript.

### Live Demo

GitHub Pages deployment is being configured. The verified live-demo link will appear here once publishing is complete.

### Features

- **SmartReply** — Context-aware, hardcoded customer response suggestions.
- **Multiple Reply Tones** — Empathetic, personalized, and professional responses.
- **SmartNotes** — Generates formatted internal case notes when requested, ready to edit and save privately in the demo timeline.
- **Customer Personalization** — Demonstrates contextual information such as pet names, wedding events, and device details.
- **Chat & Email Support** — Simulated customer support interactions.
- **Editable Responses** — Agents can review and customize suggestions before sending; press Tab in the reply editor to accept SmartReply.
- **Interactive Workspace** — Reply/Internal Notes tabs, case navigation, and resizable composers.

### Technology

- HTML5
- CSS3
- Vanilla JavaScript

No dependencies, build tools, server, or installation are required. Session drafts and messages are held in memory and reset when the page is reloaded.

### Getting Started

Clone the repository:

```sh
git clone https://github.com/TajwarRahman03/DemoModel.git
cd DemoModel
```

Open `index.html` in a modern browser. The stylesheet and script load directly from the same folder.

Select a case in the inbox to try chat or email replies. In chat, switch to **Internal Notes**, then choose **SmartNotes → Auto Generate Notes** to create an editable note. Chat replies can be sent with Enter; email replies and internal notes use their respective **Send reply** and **Save Note** buttons.

### Disclaimer

This project is an interactive demonstration using fictional customer information and hardcoded response suggestions.

No live AI model, backend, customer support platform, or shipping service is connected. Replies, replacement identifiers, and troubleshooting conversations are simulated; no messages, orders, returns, or shipping requests are actually submitted. Internal notes are a visual demonstration of private case documentation, not a secure storage service.
